# Contributing to Hearthkeep

Thanks for helping improve Hearthkeep!

## Reporting bugs and requesting features

Use the **Feedback** links in the app footer, or open an issue directly:

- [Report a bug](https://github.com/lance6x5/home-maintenance-tracker/issues/new?template=bug_report.yml)
- [Request a feature](https://github.com/lance6x5/home-maintenance-tracker/issues/new?template=feature_request.yml)

A free GitHub account is required. Please don't include personal data.

## Triage flow

1. Every new issue gets the `triage` label automatically (plus `bug` or `enhancement`).
2. The maintainer reviews it, removes `triage`, and relabels or closes it as needed.
3. Work happens on a branch, then a pull request that says `Fixes #N` so the issue closes on merge.
4. Changes are recorded in [CHANGELOG.md](CHANGELOG.md) and shipped in the next release.

## Development

See the README for `npm install`, `npm test` and `npm run build`. Please add or update unit tests in `tests/` for logic changes.
